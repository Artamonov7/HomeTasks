Программа «expanse»
Что вычисляет

Протяжение скобочной системы – количество неделимых подсистем в её записи.

    ε → 0

    ( ) → 1

    ( )( ) → 2

    (( )) → 1 (одна неделимая система)

    ( )(( )( )) → 2

Грамматика с действиями
text

S → ( S ) S   { $$ = $4 + 1; }
S → ε         { $$ = 0; }

Стартовый символ P выводит результат.
Запуск
bash

./expanse

Введите скобочную строку (только символы ( и )) и нажмите Enter. Программа напечатает протяжение.

Пример:
text

Enter a bracket string: ()(())
expanse: 2

Программа «calculator»
Что вычисляет

Арифметические выражения с целыми числами, операторами +, -, *, / и круглыми скобками.

    Левая ассоциативность

    Приоритет: * и / выше, чем + и -

    Обработка деления на ноль (выдаётся ошибка, результат = 0)

Грамматика
text

s     : пусто | s expr '\n' | s '\n'
expr  : expr '+' term | expr '-' term | term
term  : term '*' primary | term '/' primary | primary
primary : NUMBER | '(' expr ')'

Семантические действия выполняют соответствующие арифметические операции.
Запуск
bash

./calculator

Вводите выражения по одному в строке, завершая переводом строки. Для выхода нажмите Ctrl+D.

Пример:
text

Calculator (integers, + - * /). Press Ctrl+D to exit.
2 + 3 * 4
Result: 14
(10-2)/4
Result: 2
5/0
Error: division by zero
Result: 0
